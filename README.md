🚀 ai 기반 설비 예지보전 PoC_WBS (Ai_Poc_Monitoring)

스마트폰 센서 및 AI를 통해 설비의 고장 징후를 파악하 안드로이드 애플리케이션입니다.

### 🛠 Tech Stack
- Mobile App ;	Flutter (Dart)	UI 및 비즈니스 로직
- Native Bridge	; Swift / Kotlin / C++	고속 센싱 및 FFT 연산
- Backend ;	Python (FastAPI)	빠르고 가벼운 API 서버
- Database ; PostgreSQL (TimescaleDB)	시계열 데이터 관리
- AI Framework ; PyTorch or Scikit-learn	Autoencoder 모델 구현
- Infra ; AWS (EC2, RDS)	클라우드 인프라

### 📅 프로젝트 일정
- **1주차:** 데이터 수집 기반 다지기 (Data In)
- **2주차:** 엣지 컴퓨팅 및 신호 처리 (Process)
- **3주차:** 클라우드 파이프라인 구축 (Data Out)
- **4주차:** 비지도학습 AI 모델 구현 (Intelligence)
- **5주차:** 통합 테스트 및 MVP 완성 (Feedback)
